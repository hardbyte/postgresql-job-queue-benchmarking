What this system is built around

A PostgreSQL job framework with a shared format across language clients.

A useful starting point

Useful when a PostgreSQL job lifecycle and transactional application integration are central; current clients share a cross-language job format. The repository benchmark measures the Go adapter, not every language implementation.

Editorial fit, based on the cited design. Verify against your workload.

Claiming & concurrency

Documented

PostgreSQL claims use FOR UPDATE SKIP LOCKED; OSS clients set per-queue worker counts. Cluster-wide concurrency controls are a Pro feature.

Transactional enqueue

Documented

InsertTx can commit a job atomically with application changes in the same PostgreSQL transaction. Go also supports JobCompleteTx for completion plus local writes; this does not cover external side effects.

Transaction integration ↗ Transaction integration ↗ Transaction integration ↗

Crash recovery & retries

Documented

Ordinary workers execute at least once; failed completion persistence or a process crash may cause another execution. Retry policy is configurable with a finite attempt budget.

Recovery and retries ↗ Recovery and retries ↗

Delayed & recurring work

Documented

Delayed jobs and periodic/cron insertion are available. OSS periodic schedules are held in leader memory and reset across restarts/elections; durable periodic schedules are Pro.

Uniqueness / deduplication

Documented

Unique jobs use a partial unique index and selected argument, kind, period, queue and state dimensions. Uniqueness controls insertion, not exactly-once execution.

External effects still need a boundary

Application-level inference: recovery or repeated consumption may repeat external operations. Database transaction or acknowledgement guarantees do not, by themselves, atomically include another provider’s effects.

Open source & editions

River Pro adds paid extensions. The reviewed Go documentation distributes Pro as a private module; the Ruby docs describe a separate private riverqueue-pro gem. Feature/API parity across SDKs was not established.
